# COMP 490: AI Software Engineering

## Project Overview

This repository contains a Python application developed for COMP 490. It is
intended to be explored and extended with AI-assisted engineering tools.

## Development Guidelines

- Follow Python coding conventions.
- Use modular architecture.
- Separate API, business logic, and persistence.
- Write tests for new functionality.
- Avoid unnecessary dependencies.
- Document significant architectural decisions.

## Codex Workflow

1. Analyze the requested task.
2. Propose an implementation plan.
3. Identify affected files.
4. Implement changes incrementally.
5. Run relevant tests.
6. Summarize changes and limitations.

## Engineering Expectations

- Do not assume generated code is correct.
- Preserve existing functionality.
- Explain significant design decisions.
- Update documentation when appropriate.

## AI-Assisted Development Guidelines

This repository is a learning environment. Students remain responsible for
the code they submit and should be able to explain how it works.

- State the goal and constraints before asking an AI tool for help.
- Review generated code for correctness, security, accessibility, and project fit.
- Run relevant tests and record meaningful AI-assisted changes in
  `docs/ai-development-journal.md`.
- Do not provide secrets, private data, or sensitive credentials to AI tools.
- Prefer small, reviewable changes with clear commit messages.
